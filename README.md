### Roman Oliinyk

Founder of **PayCore Media, Inc.**, the company behind **[Entropy Protocol](https://github.com/entropy-ep1/entropy-protocol)**: an open standard that proves where an AI-written text came from and whether it has changed.

- **Entropy Protocol.** The model seals a text while it writes it. Any copy can be checked later, and a single changed character is traced to its sentence. Open source (Apache-2.0), `pip install entropy-protocol`, live demo at [entropyprotocol.org](https://entropyprotocol.org).
- **Background.** Ten years in network security: security systems, data-leak protection and standards work, much of it for large US companies under non-disclosure agreements. Graduate of the Dnipro mining university, now Dnipro University of Technology.
